## Public delivery and Pi compatibility

The release transaction still contains exactly ten public packages. The existing
`taskflow-mcp-core` package compiles and includes the private implementation under
`dist/control/`, with `taskflow-control`, `taskflow-project-admin` and an installed
`CONTROL_GUIDE.md`. No private package or workspace checkout is needed at runtime.
The [release guide](../../RELEASE.md) documents the bundled binary, local-tarball
acceptance, first default-auto run and version-skew/upgrade behavior.

Pi 1.0.0 acceptance above stays labeled 1.0.0. Draft #181's source head
`063282bc41ab233ca2d50f7dde8f0d88e86b31e8` independently verified 0.80.3/0.85.1/1.0.4.
This candidate preserves #142's checkpoint/usage/recovery changes while importing
its compatible explicit-tool filter and real CLI fixtures. The local source matrix passed 277 adapter tests per selected SDK: actual Pi
1.0.4 passed 28 CLI controls on Node 22/24; 0.80.3 and 0.85.1 each passed
12 CLI controls on Node 24. Pi 1.0.0 and 1.0.4 each separately passed
17 lifecycle and two crash/restart cases. Final installed acceptance is bound
to the frozen commit in the external handoff; neither #181's CI nor older
1.0.0 results replace it.

The filter also closes a reproduced Pi 1.0.4 `read,codemode` resource path:
excluding only `mcp__*` still permitted native MCP resource reads. Native
resource tools are now excluded unless explicitly selected by exact name or
star selector. A full `*` or explicit `mcp__` selector retains Pi's native
MCP opt-in semantics; this filter is not an OS sandbox.

## Retained limits and release gates

- Recovery requires provable dead ownership and safe checkpoint/quiescence;
  ambiguous TE mutations remain unknown. Forced release is an explicit audited
  operator override, not proof that side effects have ended.
- The synchronous S4 DSL and optional event kernel retain their documented
  scope. Full kernel default-on, arbitrary advanced DSL horizon, native sandbox,
  live vault/service backends and multi-user console are not newly claimed.
- Historical authenticated Codex/Claude checks are versioned evidence. Fixture
  MCP and local Pi providers are not new live-provider authentication acceptance
  for OpenCode/Grok/Hermes or every TUI combination.
- Final candidate source, public bundle, installed process tests and artifact
  hashes must agree. Its remote CI is pending until explicitly authorized.
- Registry artifact verification, authorized main/tag/npm/GitHub Release and
  the single original publisher handoff remain publication gates. See the
  [current scoreboard](./1.0.0-ga-scoreboard.md).
