## Current implementation and actual regression evidence

- Pi 1.0 retry/compaction, tool usage, supported RPC approvals and headless
  rejection are implemented. Pi 0.80.3 compaction remains compatible.
- Pi and MCP save every runtime checkpoint. Real Pi quick/slow phase chains
  survive SIGKILL at approval, reject a living owner, resume in a fresh Pi,
  reuse completed effects once, preserve parent bytes and use the new run ID.
- Recovery requires ESRCH, unchanged canonical path/device/inode, a recorded
  untimed approval wait and a DAG barrier against other runnable work. Unknown owners,
  missing metadata, changed roots and potentially active children fail closed.
  A real EACCES injection with a surviving parallel script tests the unsafe
  stale-marker window. This does not claim arbitrary in-flight child recovery.
- UDS bounded frames, absolute hello deadline, full response-branch validation
  and safe numeric counters have 54 independent process cases. Unknown TE
  handles remain ambiguous. Store values cannot mutate authoritative records.
  Copied/moved/replaced store directories are rejected before recovery writes;
  the complete explicit clone/rebind/registry workflow is still missing.
- The checked-in host baseline loads through the strict evidence validator.
  All four historical exact targets remain resolve-only and sandbox rejected.
  Six-host implementation notes are separate; no Hermes live probe is claimed.
