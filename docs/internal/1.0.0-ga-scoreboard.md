## Final release follow-up

The 2026-10-08 production audit found eight website dependency advisories.
Next 16.3.8, Sharp 0.35.5 and source-map-js 1.2.2 close them: isolated frozen
install, production export and production audit (zero advisories) pass. All
thirteen non-website lock importers, release package versions and Pi pins are
unchanged; supply-chain protections and release-age policy remain enabled.

The first follow-up Plugin Security Scan identified a synthetic process birth
token literal in `singleton.test.ts`, not a live credential. It now uses a
runtime UUID, preserving assertions; all twelve singleton cases pass on each
Node runtime. Scanner pins, thresholds and Cisco coverage remain unchanged.
The failed scan is retained as historical evidence; only final-head results
can satisfy the release gate.

Current installed runtime evidence (Node 24.21.0, implementation `472bb98`):
Pi SDK 1.0.4 passed nine actual PTY/TUI cases (approve/reject/edit, regular mode,
Escape/Ctrl-C, timeout, confirmation and a 300-line proposal). Codex CLI 0.160.0
passed live three-phase dataflow and declared filesystem-effect execution;
Claude Code 2.1.293 passed live two-phase execution. These use native existing
authentication and isolated project/session state, with no credential copies.

Native Pi live-provider access is **BLOCKED**: the configured channel returned
HTTP 403 restricting requests to official Claude Code. No bypass was attempted.
OpenCode, Grok and Hermes live binaries were unavailable. Their protocol/fixture
checks remain separate; no current live-provider pass is claimed for these
four hosts. Pi CLI/TUI fixture evidence is actual process/protocol coverage,
not native model authentication. These environment coverage gaps must remain
visible in the release record.

## Explicit boundaries

Unix UDS is supported; Windows named pipes remain non-GA under P13. The CLI
executes scripts; configured agent runners remain an embedded-provider choice.
Resolve-only containment and admission-time revocation do not claim an OS sandbox.
Unknown effects retain capacity unless an operator explicitly overrides it;
force release does not prove process termination or produce a terminal Receipt.
Plan edits preserve the DAG. Logical compaction retains the physical journal.
Live vault/service backends, invisible unmanaged legacy writers, arbitrary
in-flight recovery and every host/TUI combination are not implied by these gates.

Historical live Codex/Claude and prior SDK results remain evidence at their
recorded versions. Local deterministic-provider Pi processes are actual CLI/MCP
protocol tests, not fresh live-provider authentication. No release decision may
be inferred from a test count, private label, old remaining-work table or green
CI for another SHA.
