The supported stable scope is the mature DAG/DSL/six-host/declared-target
transaction contract. Private control-plane wire contracts remain proposed;
parked approval/Receipt/WebUI/global coordination/Windows pipes are not
accepted features. CharterArc stays independently experimental. Pi interactive
approval and fail-closed MCP/headless rejection are existing runtime features,
separate from the unfinished control-plane approval protocol.

Local full logs are retained in the parent task workspace at
`work/taskflow-release-logs/`; they are not shipped in npm packages. Earlier
red runs are retained: macOS `/var` canonical-path assertions and detached
cleanup race; hard-coded DSL version; a transient release-regexp edit during
parallel integration. The frozen source suite and affected E2Es pass after
the fixes. No red run is treated as an acceptance pass.

Do not mark 1.0 released or GA from a candidate build, green test count, fixture
MCP, prior PR CI or historical live evidence. The publication row requires the
actual authorized main/tag/registry/GitHub evidence for all ten artifacts.
