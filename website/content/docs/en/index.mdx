The complete approved Control Plane, including WebUI, remains required for 1.0 acceptance; current private workspace packaging is not a waiver.

taskflow is a declarative runtime for coding-agent workflows. It turns a graph into a verifiable execution contract, runs phases in isolation, and keeps intermediate transcripts out of the host conversation. The 1.0 contract includes **Trusted Effects**: a typed declaration and resource-controlled commit path for admitted filesystem effects.

</Callout>

## The declared-effect contract

<Steps>
  <Step>
    **Declare.** Attach a closed `effects[]` list to a phase. Each effect names its kind, typed target, purpose, and optional confidentiality/integrity labels.
  </Step>
  <Step>
    **Verify and admit.** Validate the EffectIR, resolve `PathRef`, check information-flow labels and mutating-path overlap, then bind the declared target to a resource intent.
  </Step>
  <Step>
    **Stage and commit.** The resources layer snapshots, leases, journals, stages, and atomically commits the declared filesystem target — or restores and rejects when the transaction cannot complete.
  </Step>
  <Step>
    **Explain.** Query `taskflow_why_effect` or the core `why-*` APIs for structured, ledger-backed reasons. Declaration alone is never presented as authorization.
  </Step>
</Steps>

## Release boundary

The implemented baseline and outstanding 1.0 requirements have distinct acceptance states:

- **Trusted Effects MVP:** the implemented baseline; it does not alone close the 1.0 scope. It covers EffectIR, typed refs, labels, resource-controlled filesystem transactions, overlap admission, host-baseline honesty, and ledger-backed `why-*` explainers.
- **Experimental Control Plane:** private workspace Unix UDS/store code with proposed wire contracts; admission, parked approvals, receipts, global coordination and WebUI remain incomplete and are required for 1.0 acceptance.

Read the [MVP freeze in the repository](https://github.com/heggria/taskflow/blob/main/docs/internal/0.3.0-trusted-effects-mvp.md) and the [0.3-C plan](https://github.com/heggria/taskflow/blob/main/docs/internal/0.3-c-control-plane-plan.md) for the normative scope.
